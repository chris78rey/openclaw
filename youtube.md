## Descripcion larga

En este video te muestro como crear un sistema RAG con OpenClaw para responder preguntas sobre tus propios documentos usando Telegram.

Vas a ver como conectar OpenClaw con una API RAG, indexar documentos, consultar informacion desde colecciones y dejar listo un flujo util para clientes reales.

Si quieres montar un asistente documental con control de acceso por cliente, limites de consultas y busqueda sobre tus archivos, este video te ahorra bastante tiempo de prueba y error.

Mira el video completo y revisa el repositorio para replicarlo paso a paso.
